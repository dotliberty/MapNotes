# MapNotes 1.2.3.1

- Continuous map zoom, pinch and animated travel to the current location.
- Animated photo-card entry, movement and removal with hit testing at current positions.
- Menus expand from their triggering buttons; Cancel/Back collapse anchored menus. Item selection and other exit paths still use immediate native dismissal.
- Camera icons rotate smoothly with the phone without rotating the portrait layout or changing JPEG orientation logic.
- Camera screen expands from the + photo button. Front/back switching uses an outgoing preview snapshot when available and waits for the incoming preview before completing.
- More visible button press/release feedback and walk-state reactions.

Official APK: package ru.main.explorer, versionCode 36, original release signing certificate. It updates the stable MapNotes application; it is not the separate debug build. Back up important data before updating; do not uninstall the existing app.

Verification: 241 Android/JVM tests passed, 3 external-data opt-in tests skipped, zero failures/errors. Resource, pure-geometry and signing checks passed. Physical-device camera behavior, GPU frame pacing and GPS/service timing remain unverified; no claim of zero dropped frames.
