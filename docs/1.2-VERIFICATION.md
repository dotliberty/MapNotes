Это beta для визуальной приёмки, не объявленный готовым релиз 1.2. Исследован официальный веб-атлас HoYoLAB, а не весь внутриигровой интерфейс Genshin (см. 1.2-VISUAL-RESEARCH.md).

APK MapNotes-1.2.0-beta.1-debug.apk ставится как отдельное приложение MapNotes beta DEBUG и НЕ обновляет установленный MapNotes; доступ к его существующей БД/фото автоматически не получает. Основное приложение удалять не нужно. Временная debug-подпись не гарантирует обновление следующих debug-сборок. Релизный ключ не использовался.

Телефон, аппаратные камера/GPS, фактическая плавность анимаций и Android 15, пользовательская миграция, крупные системные шрифты и полная accessibility-приёмка не проверены. Геоданные, БД и оригиналы пользователя не изменялись.
