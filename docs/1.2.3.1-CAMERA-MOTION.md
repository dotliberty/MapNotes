# MapNotes 1.2.3.1 / versionCode 36

## Changes

- Camera icon orientation now follows rounded physical orientation via a 300 ms shortest-angle animator. Only icon geometry and zoom label rotate; portrait layout, preview transform and JPEG rotation calculation remain separate. Icon rebinding during periodic status refresh retains the current angle. Pause cancels rotation.
- Camera entry expands the camera root from the actual + photo button bounds over 420 ms. MainActivity resolves the button after permission acceptance and sends screen bounds in an explicit Intent; launch waits for attached layout, avoids default Activity transition and is not replayed on saved-state recreation.
- Front/back switch retains a bounded 720px-wide snapshot over the restarting TextureView for its outgoing 220 ms flip, then reveals incoming preview over 280 ms after ready preview update. If a snapshot is unavailable the existing live-preview transition remains. Failure/pause clears the overlay and recycles its bitmap. Hardware readiness is never manufactured by animation.
- Shared button compression is now 0.94 over 110 ms with 260 ms release, plus ripple on styled native buttons; callbacks remain immediate.
- Anchored menus retain expansion from button pivots and now collapse for negative-button cancellation and Back. Negative callbacks are guarded against duplicate taps. Item selection, positive buttons and outside dismissal retain native immediate dismissal; not all exit paths are animated.
