# MapNotes 1.2.4

## Changes

- Illustrated atlas-style interface: navy panels, parchment actions, gold frames, compass ornaments and redesigned map controls, menus, walk history and photo gallery.
- Camera layout with side controls, bounded zoom buttons, gallery/mode actions and an aperture-style shutter. Existing map and menu motion retained.
- Safer camera switching: animate a snapshot instead of the live Camera2 output; do not recycle a snapshot while queued draws may still use it; guard repeated/cancelled transitions and retain manual mode recovery after device errors.
- Readable formatting across the application, tests and build tools, with pinned formatters and a read-only formatting gate.

## Install

Download `MapNotes-1.2.4.apk` and `SHA256SUMS`. This is the official, non-debug application: package `ru.main.explorer`, versionCode **37**, signed with the existing release certificate (verified against 1.2.3.1 and the original signing workflow). Install over the previous official version; do not uninstall or clear app data. The separate debug app is not replaced by this APK.
