# Проверка MapNotes 1.3.2

## Статус подготовки

Владелец 11.11.2026 одобрил стабильный выпуск проверенного кандидата оптимизации под версией **1.3.2**. Метадата выпуска: versionCode **55**, package `ru.main.explorer`, minSdk26/targetSdk35. Код оптимизации соответствует тестовой 1.3.1.2/code54; при подготовке версии меняются метаданные и публичная документация.

Production APK подписан прежним ключом через защищённый workflow и независимо проверен перед публикацией. Окончательный результат GitHub-публикации подтверждается отдельным readback релиза и его assets; локальная проверка APK сама по себе не является подтверждением публикации.

## Что проверяется

- Полный Android/JVM release-набор, pure GPS/visibility/region/message-проверки, EN/RU-ресурсы, formatter gate, служебные тесты metadata/signing/formatting.
- Официальный package/versionCode/non-debug flag, launcher, min/target SDK, APK v2/v3, совпадение единственного production-сертификата с опубликованной 1.3.1, zipalign, ZIP CRC и SHA-256.
- Согласованность release commit/tag/remote main, stable/latest-статус и побайтовый readback APK/checksum assets.

Свежая проверка **1.3.2/code55**: **49 suites / 411 tests / 408 passed / 3 external opt-in skipped / 0 failures/errors**, 1m34s. Дополнительно прошли pure-проверки (14 GPS, 206 visibility, 39910 region/tile, 9 message), localization 3/3, resource audit 505 EN/RU pairs / 320 direct references, 17 служебных unittest и полный pinned formatter gate (107 Java / 14 Kotlin / 10 Python / 10 XML / 4 Gradle). Отрицательные signing-policy сценарии ожидаемо печатают argparse error; общий результат OK.

Unsigned SDK release собран и проверен zipalign/aapt2: `ru.main.explorer`, 1.3.2/code55, min26/target35, без debug-флага. Локальный `build/MapNotes-1.3.2-unsigned.apk` имеет SHA-256 `f1770605064f59ca326024b12f1ddf94357b2835b4e773b3fcc1fec7ea8333fb`. Это не устанавливаемый production-артефакт; его hash не заменяет hash будущего подписанного APK.

## Воспроизведение

Toolchain: JDK21, Android SDK35/build-tools36.0.0, Python3.10+, Gradle8.9. На Windows использовать действительный Python, а не заглушку WindowsApps. Пути SDK/JDK/Gradle задаются локальным окружением по [BUILDING.md](BUILDING.md).

```powershell
python tools/test.py --variant release --gradle $gradle
python tools/test_pure.py
python tools/verify_resources.py
python -m unittest discover -s tools -p "test_*.py"
python tools/format_code.py --check --java-formatter <google-java-format-1.24.0-all-deps.jar> --black-path <black-26.10.1-library> --kotlin-formatter <ktfmt-0.53-jar-with-dependencies.jar>
python tools/build.py --gradle $gradle --keystore <existing-production-key> --previous-apk <verified-official-1.3.1.apk>
git diff --check
```

Пароль передаётся штатным защищённым workflow через `MAPNOTES_STORE_PASSWORD`; секреты, ключи и локальные credential-файлы не являются исходниками и не публикуются. XML/HTML Gradle остаются generated build-артефактами.

## Границы результатов оптимизации

Native Canvas-регрессии проверяют точность движения, fractional transforms, interleaved-порядок, глобальный бюджет 80000 вершин, source invalidation, закрытие queued work и композицию ready viewport/tiles. В детерминированной тёплой fixture 32/32 движущихся кадра сохраняют полное покрытие при заблокированных workers; это не утверждение о мгновенной готовности новых данных.

В холодной синтетической fixture code54 (1080×2340/density3, 60000 detail-дорог, живые decode/RouteFrame, 144 позиции) p95 полного UI draw — около 23.9 ms, но средняя доля готового покрытия — около 40.9%, полностью готовых кадров — 4/144. Новые тяжёлые viewport завершаются после остановки. Эти исторические desktop-числа не являются FPS телефона и не гарантируют тот же результат на другом архиве/устройстве.

Владелец одобрил stable после телефонной проверки; модель/источник и полный аппаратный профиль в локальных измерениях не установлены. Общий пик Java/native/GPU memory, батарея, вся матрица внешнего WorldMap, аппаратной камеры/GPS и чрезвычайно больших насыщенных экранов не измерены. Локальные cache/work budgets не являются общим пределом процесса. Эти ограничения сохраняются и после разрешения выпуска.
