# MapNotes 1.3.2.2 — доступность карты и очистка загрузок

**Стабильная версия 1.3.2.2, 13.11.2026.** Дима разрешил выпуск и подтвердил телефонную проверку **mask-cancel**, побайтово совпадающего с официальным APK. Боба принял код и APK после независимого review и полного прогона **469 passed / 3 skipped**. Проверки и отдельное подтверждение публикации — в [verification](1.3.2.2-VERIFICATION.md).

## Русский

- **Скачанная карта лучше сохраняется при масштабировании.** Исправлены переходы между обзором и подробностями, в том числе при фоновой подготовке соседних областей. Готовое покрытие используется только там, где исходные данные остаются актуальны.
- **Крупные области обрабатываются в фоне.** Потоковое дисковое представление позволяет использовать источники, которые не помещаются в кэш геометрии целиком. Линия маршрута готовится независимо от маски раскрытия; прежние локальные бюджеты памяти сохранены.
- **Удаление всех скачанных областей.** Новый пункт меню карты очищает полные, незавершённые и повреждённые загрузки, автоматически загруженные улицы/здания, спутниковые изображения и связанные временные кэши. Перед удалением показываются состав операции и подтверждение.
- **Дневник сохраняется.** Очистка карт сохраняет историю прогулок, исследованную территорию и прогресс, фотографии, заметки, зоны, подключённые и отдельно импортированные MBTiles. Сеть карты ставится на паузу; включить её снова можно кнопкой **«Сеть»**.
- **Безопасное завершение фоновой работы при очистке.** Исправлены гонки поздних загрузок и отмена построения маски/чтения стен. При частичной ошибке очистка сообщает о незавершённой операции и допускает повтор.
- **Ручной экспорт диагностики карты.** Меню открывает системный выбор файла. Экспорт содержит ограниченную историю технических событий и текущие состояния источников; координаты, пути, фото и заметки в него не включаются. Автоматической отправки нет.

Повторное использование векторных загрузок между областями с разным центром/размером готовится отдельно для **1.3.2.3**. Эта версия ещё может повторно скачивать пересекающиеся векторные данные.

## English

**Stable version 1.3.2.2, November 13, 2026.** The owner approved the release and confirmed testing **mask-cancel** on a phone; that APK is byte-identical to the official asset. Boba accepted the code and APK after independent review and a full **469 passed / 3 skipped** run. Checks and the separate publication record are documented in the [verification record](1.3.2.2-VERIFICATION.md).

- **Downloaded maps remain available more reliably while zooming.** Fixed overview/detail transitions, including background preparation of neighbouring areas. Ready coverage is reused only while its source data remains valid.
- **Large sources are prepared in the background.** A streamed disk representation handles sources that cannot fit in the geometry cache as a whole. Route lines are prepared independently of the reveal mask; existing local memory budgets are retained.
- **Delete all downloaded areas.** A new map-menu action removes complete, unfinished and corrupt downloads, automatic street/building downloads, satellite images and their temporary caches. The app explains the scope and asks for confirmation.
- **Your journal is retained.** Map cleanup preserves walk history, exploration progress, photos, notes, zones, and connected or separately imported MBTiles maps. Map networking is paused; tap **Network** to resume it explicitly.
- **Background work is retired safely during cleanup.** Fixed late-download races and cancellation of reveal-mask/wall work. Partial cleanup errors are reported and can be retried.
- **Manual map-diagnostics export.** Choose a destination through the system file picker. The export includes a bounded technical event history and current source states, without coordinates, file paths, photos or notes. Nothing is sent automatically.

Reuse of vector downloads across areas with different centres or sizes is planned separately for **1.3.2.3**. This version can still download overlapping vector data again.
