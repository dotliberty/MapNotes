# Камера 1.2.0-beta.2 (versionCode 29)

## Реализовано

- Направление: ручной список доступных Camera2 device IDs, включая фронтальные. Объектив: ручной список устройств и физических IDs выбранного направления; подписи содержат ID, parent ID и фокусное расстояние в мм, без угадывания по модели телефона.
- Физический объектив API 28+: открывается родительская логическая камера, обе OutputConfiguration (preview/JPEG) привязываются через setPhysicalCameraId. Автоподмены при ошибке нет. JPEG+preview конкретного физического сенсора не входит в универсальную гарантию Android; неработающий режим объясняется, затвор отключён, ручной выбор другого объектива/размера остаётся доступным.
- Размеры JPEG только из StreamConfigurationMap выбранного устройства/сенсора; настройка раздельная для каждой пары parent/physical ID. Preview подбирается по пропорциям. Неподдерживаемая сохранённая размерность не отправляется камере.
- UI locked: ориентация интерфейса при входе сохраняется, физический поворот не переносит затвор. JPEG_ORIENTATION считается отдельно по SENSOR_ORIENTATION + OrientationEventListener, со сменой знака для фронтальной. Preview учитывает sensor/display rotation и зеркалит фронтальную камеру; JPEG отдельно не зеркалится.
- API 30+: CONTROL_ZOOM_RATIO только при наличии request key и корректного CONTROL_ZOOM_RATIO_RANGE. Иначе центрированный SCALER_CROP_REGION в границах advertised max digital zoom. Для physical ID crop только через advertised physical request key. Нет key/range — «Зум недоступен». Preview и JPEG получают один зум; переключения объектива приложением от зума нет. Выбранная логическая камера всё же может переключать сенсоры внутри HAL — это явно объяснено в UI.
- Camera2 callbacks и изменения состояния на main Handler. Generation защищает старые device/session/image callbacks и открытые диалоги; новый open ждёт onClosed прежнего device, включая незавершённый open. Во время capture смена камеры/размера заблокирована. Pause закрывает session/device/reader/surface, отключает listener и location updates.
- EN/RU, native кнопки/диалоги/SeekBar, content descriptions, live-region статуса сохранены.

## Проверка и границы

Robolectric не моделирует сенсор, HAL и реальное качество JPEG. Новые CameraControlsTest проверяют crop/zoom policy, пространства ID и preferences, locked manifest, busy state, pending close, восстановление после неподдержанного режима и обе формулы JPEG. Существующие CameraUiTest/CameraLayoutTest остаются; localization test теперь выставляет active/ready перед открытием диалога размеров, как требует новый lifecycle guard.

`adb devices -l` 08.11.2026: список устройств пуст. Pixel 7 Pro, доступность его телеобъектива/физического JPEG, реальный front preview, поворот JPEG/EXIF, многократные быстрые смены и возвращение из background аппаратно НЕ проверены. Нет обходов OEM, private APIs, скрытых camera ID или обещания наличия конкретного объектива. Не было установки, удаления приложения, доступа к данным владельца или push.
