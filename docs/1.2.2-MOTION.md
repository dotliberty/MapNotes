# MapNotes 1.2.2 — motion (versionCode 34)

## Scope

- Preserved and completed the unfinished AtlasMotion / AtlasUi / PhotoActivity changes after 1c90882.
- Shared buttons, including styleButton: interruptible 0.965 pressed scale (90 ms), 180 ms release; native click handlers are not deferred. Dialogs, including gallery: shared 240 ms alpha/10 dp entry; photo reveal 180 ms.
- Photo double-tap reset: 260 ms interpolation of image matrix and logical zoom, interruptible on touch, new image, resize and detach. Pending fit callbacks are removed on detach and replacement. No CameraActivity/camera lifecycle changes.
- Map button zoom, showPlace and locate: deliberately conservative 180 ms alpha softening, NOT interpolated geographic zoom or animated pan. Target coordinates/zoom are applied immediately. No scale/translation of MapView, no synthetic input transforms, no per-animation-frame camera/route/geometry updates. Pinch zoom does not start this transition; touch-down cancels it. GPS-follow behavior is unchanged. Existing ordinary redraw/geometry costs are not eliminated.
- ValueAnimator.areAnimatorsEnabled is checked on launch. Zero system animator scale uses immediate final state; Android animators handle their global duration scale. Shared view animations cancel/settle on detach. No delayed clicks.
