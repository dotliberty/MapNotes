# MapNotes 1.2.4 — atlas reference redesign (code 37)

## Scope

Implemented the five supplied design references as native Android UI, not screenshot backgrounds: navy surfaces, parchment primary actions, bevelled double gold borders, compass/star/corner ornaments, serif headings and a decorative scenic banner. Native controls retain text, callbacks, accessibility labels and minimum touch sizes. Existing fractional map motion, anchored menu transitions, camera rotation/switch lifecycle and photo-card animation remain.

- Main: scenic atlas banner and centered title; parchment + photo and start-walk actions; circular map controls; ornamental footer/history/download controls. Network toggle moved clear of the scale bar. Landscape retains a scrollable action rail; compact EN/RU views verified.
- Map menu and history: shared ornamental dialog/panel surfaces and framed native list rows. AtlasRows preserves adapter identities, enabled state, checked item and native selection callbacks.
- Gallery: framed thumbnails, dates/notes and parchment return button; recycled thumbnail loading and retained viewer/list navigation remain.
- Camera: banner, paired header controls, left-facing/lens rail, right +/-/ratio controls, corner guides, aperture shutter and gallery/modes actions. Zoom buttons use the existing metadata-aware ratio limits and generation guards. Gallery navigates back to MainActivity with explicit one-shot openPhotos; modes opens actual existing camera settings. No synthetic preview image or fabricated camera readiness.
- Contrast: icons inherit button text color, including dark icons on parchment. Busy shutter ellipsis stays visible.

Small scenic/flower assets were cropped from the owner's supplied reference and downsampled to at most 256px width. Frames, book/compass motifs and controls are procedural Canvas art. No GPT Image request or external asset download. Provenance/redistribution caveat: assets/atlas124/SOURCES.md.
