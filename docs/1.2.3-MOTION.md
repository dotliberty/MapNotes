# MapNotes 1.2.3 — spatial motion / code 35

## Implemented

- Continuous fractional map zoom (buttons, double tap, pinch) and interpolated geographic pan for locate/showPlace. Touch interrupts the viewport at its current state; repeated zoom requests accumulate. Route-frame rebuild requests are deferred while viewport animation/pinch is active, reusing existing drawing data.
- Menus wired to their triggering buttons expand from the actual screen-space anchor. A transparent full-window surface avoids clipping the panel along its travel. Dialogs without an anchor retain shared entry motion.
- Camera front/back switch uses a Y-axis flip with reconfiguration at the midpoint. Return waits for actual ready preview update; the animation does not mark hardware ready. Pause/surface destruction cancels the transition.
- Walk-state changes animate the status/start control rather than replaying on every refresh.
- Map photo cards use stable photo identity for entry, displacement and exit. Hit testing uses current animated card geometry and excludes exiting cards. Photo reset and shared button motion from 1.2.2 remain.
- Disabled system animation scale and detach/cancellation paths have regression coverage.

## Limits

JVM/Robolectric verification is not physical-device acceptance. Actual device GPU frame pacing, Camera2 front/back behavior and GPS/service timing remain unverified. Existing map drawing and dense photo layout can still be expensive; no claim of zero dropped frames. Menu filmstrip is a controlled native dialog fixture, not every possible device size. Three external-data opt-in tests remain skipped. Debug APK updates the separate debug app, not the stable release.
