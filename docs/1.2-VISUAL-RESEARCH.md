# Визуальное исследование 1.2 — 08.11.2026

## Источник и способ проверки

Официальная **Teyvat Interactive Map — HoYoLAB**:
https://act.hoyolab.com/ys/app/interactive-map/index.html?lang=en-us

Страница реально открыта в отдельном браузерном сеансе: просмотрены карта с категориями, onboarding-подсказка, окно Update Log, раскрытая панель Switch (выбор региона). Это именно веб-атлас HoYoLAB, **не проверка всех экранов внутриигрового клиента**. Google Search заблокирован CAPTCHA, Bing не дал результатов по узкому запросу; прямой официальный атлас загрузился. Текстовое извлечение отдельной статьи не поддерживается текущим backend, поэтому статья не используется как доказательство.

## Наблюдения → собственная реализация

- **Иерархия:** карта — основное содержимое, категории/действия собраны в отдельные панели; светлый выбранный регион контрастирует с приглушёнными соседями. В MapNotes: светлая основная кнопка прогулки, вторичные офлайн/история в одной строке; камера/фото и инструменты находятся поверх карты.
- **Типографика:** чёткое разделение заголовков, категорий, подписей и вспомогательной информации; умеренное число размеров. Computed style в данном браузере: Microsoft YaHei/Neuropolitical/sans-serif fallback, TEYVAT 16px, Switch 12px, строка региона 14px. Мы не переносим их шрифты: системный serif для названия/заголовков и системный sans-serif для действий/статусов.
- **Панели:** тёмный сланец, тонкие светлые/золотые границы, кремовый акцент; Update Log имеет тёмный заголовок над светлым содержимым. MapNotes не копирует форму окна: собственные округлые navy-панели, тонкая рамка, разделители списков, прокрутка штатного Android ListView, отдельная подробная панель по нажатию на статус.
- **Инструменты:** компактный вертикальный ряд справа; крупное полезное поле карты. В MapNotes: нативные кнопки с content descriptions, 48dp высота, ripple, отдельная прокручиваемая боковая колонка в landscape. При визуальном просмотре найдено наложение сети на меню в landscape — сеть перенесена влево, результат перерендерен.
- **Анимации:** на живой странице computed CSS показывает transition/opacity 0.2s для строк регионов и элементов. В MapNotes собственное появление панели за 180ms (alpha и 8dp translation, decelerate), только когда Android разрешает анимации; бесконечных декоративных анимаций нет.
- **Фотографии:** оригинальная механика MapNotes, не заимствована из Genshin: свободная карточка ровно на GPS без якорной точки/линии; только конфликты разводятся с тонкой cubic Bezier выноской. Приоритет по постоянному photo.id, независимый от порядка списка. Совпадающая исходная точка открывает все её фото.

## Границы

Ни графика, ни иконки, ни названия регионов, ни шрифты HoYoverse в приложение не переносились. Использованы системные Android шрифты, Canvas/GradientDrawable и собственная геометрия. География/атрибуции прежних источников MapNotes сохранены. Физическая плавность на устройстве и полное покрытие accessibility/крупных шрифтов ещё требуют приёмки; это не заявляется как законченная копия интерфейса Genshin.
